# Smart Industrial IoT Fault Detection & Predictive Maintenance

## Machine Learning Internship Project 2

**Developed by:** Himanshi Arora

## Project Overview

This project uses Machine Learning to detect industrial equipment faults using IoT sensor data. The model predicts whether equipment is operating normally, requires maintenance, or has a critical fault.

## Features

- Industrial IoT Dashboard using Streamlit
- Live Sensor Monitoring
- Equipment Health Score
- Machine Learning Fault Prediction
- Prediction Confidence
- Feature Importance Visualization
- Prediction History
- Interactive User Interface

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Plotly
- Joblib

## Machine Learning Model

- Random Forest Classifier

## Dataset Features

- Temperature
- Vibration
- Pressure
- RMS Vibration
- Mean Temperature
